# Naming Research

**Purpose**

This folder contains research corpus for naming strategy, collision analysis, and trend identification.

**Scope**

The naming research supports informed decision-making about artist names and band names. It includes:

1. **First-Name Datasets** – Static first-name lists with source-specific labels; not demographic profiles
2. **Surname Research** – Historical list retained, but no validated ranking is maintained
3. **Industry Collision Analysis** – Review requirements; no current collision classifications are active
4. **Reports** – Synthesis, trends, strategy, and recommendations

**Research Standards**

- Cite authoritative sources where available (census data, industry databases, academic research)
- Document methodology, retrieval date, source categories, and limitations
- Distinguish between verified data and inference
- Do not infer identity, audience, culture, or familiarity from aggregate name frequency
- Support editorial decision-making without prescribing decisions

**Authority**

This research corpus is informational. It does not:
- Override human editorial judgment
- Create artists or bands
- Mandate naming changes

It may provide limited historical context. It does not establish demographic attributes, generational familiarity, collision risk, searchability, memorability, or name availability.

**How to Use This Corpus**

1. Review the [official source evaluation](reports/official-name-data-source-review.md) and each dataset's evidence limits
2. Use frequency lists only as historical context or an ideation aid
3. Use industry collision analysis only when current, documented searches are available
4. Apply name-selection strategy principles to future naming work

**Governance**

All research materials should:
- Document sources
- Note limitations and gaps
- Indicate confidence levels
- Support (not replace) editorial decision-making
