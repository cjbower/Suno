# Naming Research

**Purpose**

This folder contains research corpus for naming strategy, collision analysis, and trend identification.

**Scope**

The naming research supports informed decision-making about artist names and band names. It includes:

1. **First-Name Datasets** – Popular first names by decade and gender
2. **Surname Datasets** – Common surnames and origin information
3. **Industry Collision Analysis** – Current artist/band name collision assessment
4. **Reports** – Synthesis, trends, strategy, and recommendations

**Research Standards**

- Cite authoritative sources where available (census data, industry databases, academic research)
- Document methodology and limitations
- Distinguish between verified data and inference
- Preserve historical context (why these names matter to audiences)
- Support editorial decision-making without prescribing decisions

**Authority**

This research corpus is informational. It does not:
- Override human editorial judgment
- Create artists or bands
- Mandate naming changes

It supports editors by providing:
- Demographic context
- Generational familiarity patterns
- Collision risk assessment
- Searchability and memorability data

**How to Use This Corpus**

1. Review decade datasets to understand generational naming patterns
2. Consult surname research for collision assessment
3. Use industry collision analysis to identify naming risks
4. Apply name-selection strategy principles to future naming work

**Governance**

All research materials should:
- Document sources
- Note limitations and gaps
- Indicate confidence levels
- Support (not replace) editorial decision-making
