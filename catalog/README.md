# Catalog

**Purpose:** Maintain authoritative metadata, documentation, and organizational structure for all Suno Studio creative work.

**Scope:** Includes albums, repertoire, metadata schemas, and supporting documentation.

---

## Structure

- **albums/** – Album projects and documentation
- **repertoire/** – Source material and thematic organization
- **metadata/** – YAML schemas and canonical registries

---

## Albums Directory

Refer to `albums/` for individual album documentation and brief files.

---

## Repertoire Directory

Refer to `repertoire/` for source material organization, including:
- Psalms
- Daily readings
- Revolutionary War documents
- Historical documents
- Virtue literature
- Saints' lives
- Poetry

---

## Metadata Registry

Refer to `metadata/` for canonical YAML files:
- `artists.yaml` – Artist registry
- `bands.yaml` – Band registry
- `albums.yaml` – Album registry
- `songs.yaml` – Song registry
- `voices.yaml` – Voice profile registry
- `motifs.yaml` – Motif registry
