# Release Standards

**Purpose:** Define quality standards and requirements for release-ready music from Suno Studio.

**Scope:** Applies to all official releases: singles, EPs, albums, and other public releases.

---

## Quality Checkpoints

### Song Development

- [ ] Source material identified and documented
- [ ] Emotional objective defined
- [ ] Artist assignment documented and justified
- [ ] Genre selection documented and justified
- [ ] Song concept and arrangement documented

### Recording and Production

- [ ] Vocal recording meets artist production DNA standards
- [ ] Instrumentation recorded and produced cleanly
- [ ] All tracks recorded to contemporary production standards
- [ ] No technical issues or clipping
- [ ] Minimal vocal processing; emotional connection preserved

### Mixing

- [ ] Mix is clean and clear
- [ ] All elements are present and audible
- [ ] Vocal is clear and emotional connection maintained
- [ ] Instrumentation balanced and serves arrangement
- [ ] No excessive effects or processing
- [ ] Stereo imaging appropriate
- [ ] Fade-in and fade-out handled properly

### Mastering

- [ ] Mastered to contemporary loudness standards
- [ ] Frequency balance appropriate
- [ ] No clipping or distortion
- [ ] All formats delivered (streaming, CD, vinyl if applicable)

### Metadata

- [ ] Song title and artist name correct
- [ ] Credits documented (writers, producers, featured artists)
- [ ] Genre and subgenres assigned
- [ ] Artwork and cover art prepared and approved
- [ ] Release date scheduled
- [ ] Promotional and social media plan created

### Documentation

- [ ] Song metadata entered into `catalog/metadata/songs.yaml`
- [ ] Album/project metadata updated if applicable
- [ ] Artist discography updated
- [ ] Production notes documented
