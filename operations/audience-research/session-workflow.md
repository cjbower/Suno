# Research Session Workflow

## Sequence

```text
Research Question Defined
    ->
Candidate Version Frozen
    ->
Survey Version Frozen
    ->
Cohort Selected
    ->
Listening Order Randomized
    ->
Independent Responses Collected
    ->
Optional Group Discussion
    ->
Results Analyzed
    ->
Audience Research Report
    ->
A&R and Editorial Review
```

## Version Identity

Identify the exact evaluated material with:

- `demo_id`
- `development_id`
- `candidate_version`
- `audio_sha256`
- `survey_version`
- `session_id`

If any identifier or checksum is unknown, record `UNKNOWN` and disclose the limitation. Do not substitute a newer version during an active session.

## Session Integrity

Freeze the candidate and instrument before listening. Randomize listening order when comparing candidates. Collect independent responses before optional group discussion to reduce conformity effects. Document playback failures, missing responses, cohort deviations, and discussion format.

## Activation Boundary

This workflow is documentation only. Do not recruit participants, run sessions, send surveys, create accounts, or collect data in this phase.
